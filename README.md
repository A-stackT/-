# 三角洲行动 · 黑屋匹配推测系统（GitHub Pages 部署版）

一个面向《三角洲行动》玩家的**纯前端、零依赖、可离线**工具，用于推测「黑屋」匹配机制与爆率，并管理改枪码库。

> ⚠️ 本工具为玩家社区**推测性质**，参数取自百科词条、社区拆解与多位实测 UP 主的公开统计，**不代表琳琅天上 / 腾讯官方判定**。厂商未公开完整匹配与爆率算法，参数可能随版本调整。

## 功能

- **黑屋匹配推测引擎**：基于撤离率、赚损比、战损比、收益效率、战备、行为标签等多维因子，输出匹配压力档位与爆率系数，并给出归因与稳健度分析。
- **爆率模拟沙盒**：分模式（绝密 / 机密 / 常规）独立爆率池，实时判定与降档点可视化。
- **改枪码库**：内置 **461 条**经核对、去「金枪客」的改枪码，覆盖游戏内「军械库」全部 67 把枪（每把≥1 条），支持本机增删与自动归类。方案说明中原带的「g.aitags 热门」来源标注已整段清除（改为空，可选字段），**改动仅涉及描述文本，未删除或改动任何改枪码**；本机已保存的存量条目于下次载入时自动清理该标注。
- **房卡刷新点 / 本地保存路径** 等辅助页。

## 技术说明

- 单文件 `index.html`，内联 CSS + 原生 JS，**无任何外部资源、无需联网、无需构建**。
- 全部数据存于浏览器 `localStorage`（纯本地），不向任何服务器上传。
- 直接在浏览器打开 `index.html` 即可使用；移动端与桌面端自适应。

## 部署到 GitHub Pages

本目录即为可直接部署的静态站点，包含 `index.html`、`.nojekyll`、`README.md`。

**方式一：仓库根目录（最常用）**

1. 在 GitHub 新建仓库（如 `delta-force-blackroom`）。
2. 将本目录下的 `index.html`、`.nojekyll`、`README.md` 上传到仓库**根目录**。
3. 进入仓库 **Settings → Pages → Build and deployment → Source** 选择 **Deploy from a branch**，Branch 选 `main`、目录选 `/(root)`，保存。
4. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/` 即可。

**方式二：使用 `/docs` 目录**

1. 将本目录内容放入仓库的 `docs/` 目录。
2. Pages Source 选 `main`、目录选 `/docs`。

> 已附带 `.nojekyll` 文件，防止 GitHub 用 Jekyll 处理时忽略下划线文件或某些资源。

**自定义域名（可选）**：Settings → Pages → Custom domain 填写域名，并按页面提示添加解析记录。

## 本地预览

直接双击 `index.html`，或启动本地静态服务：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
